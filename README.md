Sistema Inteligente de Iluminação e Proximidade com Arduino

Projeto desenvolvido com Arduino utilizando um LED RGB, sensor de movimento e fotoresistor para criar um sistema inteligente capaz de reagir à luminosidade do ambiente e à distância de objetos.

O sistema monitora continuamente a intensidade da luz através de um fotoresistor (LDR) e detecta aproximação usando um sensor ultrassônico PING))). Com base nesses dados, o LED RGB altera automaticamente suas cores e intensidade:

🔴 Ambiente escuro ou objeto próximo → LEDs com brilho máximo  
🟡 Luminosidade média ou distância intermediária → brilho reduzido  
⚫ Ambiente claro ou objeto distante → LEDs desligados  

Componentes Utilizados  
Arduino Uno  
LED RGB  
Sensor ultrassônico PING  
Fotoresistor (LDR)  
Resistores  
Protoboard  
Jumpers
